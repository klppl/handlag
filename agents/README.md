# AGENTS.md Templates

A collection of curated `AGENTS.md` configuration files defining operational rules, architectural defaults, and communication guidelines for AI coding agents.

## 📋 Available Templates

| Template | Description |
| :--- | :--- |
| [General / Baseline](general.md) | Minimalist, low-ceremony operational rules, stack defaults (Go/Python, HTMX/Vanilla JS, SQLite), and Scandinavian design philosophy. |

## 🛠 How to Use

Copy a template into the root of your target repository as `AGENTS.md`:

```bash
cp agents/general.md /path/to/project/AGENTS.md
```
